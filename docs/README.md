# docs

- `figures/` – every figure used in the main README, one file each, generated by `scripts/plot_*.py`.
- `pipeline/` – quality-check images of the data pipeline: calibration, rim detection on all clips, tracking overlays, retargeted demonstrations.
- `results/` – the result files the README cites, copied here by `scripts/results_table.py`: `eval_<layout>_<controller>.json` (100 episodes each), `results_table.md/json`, the real-to-sim transfer checks, the world-model test summaries, and `clearance_sweep/` for the planner margin sweep.
- `media/` – GIFs: the Messi clip, tracking examples, every evaluated episode as a schematic under `<layout>/<controller>/schematic/`, and selected Panda renders under `<layout>/<controller>/panda/`.

Everything else a script produces (episode logs, SmolVLA checkpoint, sweeps) stays in `outputs/`, which git ignores.
